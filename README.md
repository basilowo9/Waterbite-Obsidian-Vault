# Waterbite-Obsidian-Vault
An obsidian vault containing a bunch of important information about the celeste map Waterbite by JuliaRRQ.

This vault is unfinished, and im still actively working on it.

some things to note about the vault

- Every image uses the ralsei modded skin, which i forgot i was using honestly (i will fix eventually probably maybe... i might be too lazy for that actually)
- A lot of gaps i felt were to easy to document a lineup for, so only the more difficult ones are listed
- All screenshots are taken with simplified graphics on because of water effect
